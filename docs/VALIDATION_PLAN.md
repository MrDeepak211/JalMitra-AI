# JalMitra AI — Validation Plan

## Farmer discovery

Conduct consent-based interviews with a target of 10–15 farmers in selected Parbhani-area villages. Record current irrigation decisions, crop and soil context, water source, electricity constraints, shared-source arrangements, phone/connectivity access and language preference. This is a target; interviews are not yet claimed as completed.

## Sensor calibration

- Collect reference soil samples across dry, intermediate and wet conditions.
- Record raw ADC values and reference moisture values.
- Repeat measurements to assess stability.
- Document sensor placement, installation depth and watering history.
- Derive calibration only from collected measurements for the selected soil.

## Advisory evaluation

- Have an agriculture expert review crop/soil thresholds.
- Test missing, stale and out-of-range sensor readings.
- Show the reason and limitations for each recommendation.
- Default to “recheck / insufficient data” when data quality is poor.

## Pilot measures

- Sensor agreement against reference samples.
- Repeatability and data completeness.
- Farmer comprehension and usefulness feedback.
- Pump run-time or water volume only where reliable baseline records exist.
- Shared schedule conflicts and participant-reported usefulness.

Do not claim water savings, yield gains or accuracy until measured and documented.
